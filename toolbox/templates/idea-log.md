# Owner idea log

Every idea the owner gives goes here, with its status, so none is lost. The master playbook section 5 is the current copy; update both.

| Date | Idea (owner's words) | Status | Where it lives | Test | Notes |
|---|---|---|---|---|---|
| | | idea / building / built / built, not proven on real equipment / fixed / not now / declined | screen or file | script or test name | decisions, what only the owner can do |

Statuses:
- **built**: works, tested, pushed.
- **built, not proven on real equipment**: tested in code or against a pretend setup only.
- **not now**: the owner decided to wait (for example the move to Render).
- **declined**: decided against, with the reason.
